WHY USE IT?
This soft helps for compose quickly texts which use repetitive sentences (for example judgments for pupils.)

HOW DOES IT FUNCTION?
It allows to send to the preferred editor a select sentence from a menù At the start you have the acquisition of the sentences memorizes in the in single file Frasario.dat text. In succession the program rustler the editor and it is prearranged for show by menù the sentences memorizes. The sentences are organized in blocks. The different blocks presents in sequence.

HOW MANY SENTENCES COULD BE INTRODUCED?
The light version works with 126 sentences (18 sentences x 7 blocks.) That completes works with 450 sentences (18 sentences x25 blocks.)

HOW DO THE BLOCKS BE IDENTIFIED?
An empty line marks the end of a block.

HOW DO YOU CREATE OR CHANGE A VOCABULARY?
Could be read/ change/ save more vocabularies. These are lines text (click on change vocabulary or use
the preferred editor.)

WHAT ARE THE RULES OF PROFEDIT?
The fundamental rule is:
- an empty line separates the different blocks of sentences;
The other rules, useful but not fundamental, are:
- a line which have the first character the . (point) it comes
unknown
it serves for introduce eventual comments in the vocabulary:
- a line which have the first character the * (symbol of the multiplication) will be show like title of the block;
- a line which have the last character the < sends to the editor a sign to go to the next line. (the symbol will be eliminated from the sentence);
- a line which have the first character < will have inserted after the cancellation of the first 5 characters (useful function for identify the line with three characters chosen to pleasure;

HOW DO YOU SECT THE CURRENT VOCABULARY?
When a vocabulary is recalled (from the page changes vocabulary), clicking on continue the content is saved in frasario.dat and it becomes the vocabulary of current use that is that readed at the start of the program.

WHICH EDITOR DIALOGUE WITH PROFEDIT?
Whatever editor could be used. For change that which is in use you must click on Change Editor of the initial page and open the soft desired.
