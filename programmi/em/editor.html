Scrivi il nome del file nel testo (in minuscolo) per usarlo: es. prova.wav, disegno.bmp
Punti caldi (modalità cliccare)

Trascina sul disegno per creare i quadrati. Il primo (azzurro) indica la risposta esatta, i rossi le risposte errate. Clic destro su un quadrato per eliminarlo. Se non metti quadrati rossi, l'alunno può cliccare in tutto il disegno.

REGOLE DELLA PROGRAMMAZIONE (dalla guida originale di EM)

Il testo scritto prima di <ese> o <con> e' la PRESENTAZIONE del livello.
Se nel testo si scrive il nome di un file .wav (es. prova.wav) verra' eseguito
il suono; se si scrive il nome di un file .bmp verra' presentato il disegno.
Scrivere il nome dei file in minuscolo.

<con>  testo CONSEGNA, associato a tutti gli esercizi seguenti
<ese>  inizia un ESERCIZIO. Sulla stessa riga si puo' indicare una risorsa:
       <ese> calcolatrice cal.exe     (menu Risorse)
       <ese> ESPERIMENTO mat.exe       (apre il laboratorio Talete)

MODALITA' DIGITARE
  (2+3)/2=
  \2.5\2,5                 piu' risposte valide (fino a sei)
  suggerimento\2.5\2,5     testo a sinistra di \ = suggerimento (gufo)
  sugg.wav\2,5             suggerimento audio

ESERCIZIO CON PIU' DOMANDE (max 7): le linee ____ vengono sostituite
dalle soluzioni via via che l'alunno risponde.
  La fotosintesi _________ avviene nelle _________.
  \clorofilliana
  \foglie

MODALITA' SCEGLIERE (lista in ordine alfabetico, ! = esatta)
  Il cane vola?
  \!falso\vero

MODALITA' SELEZIONARE (l'alunno seleziona sulla lavagna)
  Quali dei seguenti numeri e' divisore di 10
  5 3 7 9
  \"5

MODALITA' CLICCARE (punti caldi su un disegno)
  Indica la corda
  disegno1.bmp
  \|113 65 117 18\            x y larghezza altezza (in pixel del disegno)
  Il primo quadrato e' la risposta esatta, gli altri sono errati.
  Usa il pulsante "Punti caldi" accanto a un'immagine per disegnarli.

PARAMETRI (per ogni livello): punti per superare il livello (cumulativi),
secondi di gioco, punti per esercizio esatto, punti persi per errore,
tempo per rispondere, punti persi a tempo scaduto, ordine casuale (1) o
sequenziale (0). In ordine casuale gli esercizi sbagliati vengono
riproposti finche' non sono risolti.

IMPORTA: seleziona la cartella di un'esercitazione originale di EM
(il file .ESE con i suoi .bmp e .wav) oppure un file .json esportato.
Le esercitazioni sono salvate nel browser di questo computer: usa
"Esporta file" per conservarle o scambiarle con altre scuole
(un unico file contiene testo, immagini e suoni).
